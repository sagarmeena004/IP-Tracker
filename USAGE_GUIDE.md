
# Usage Guide

## Python IP Tracker

### Requirements
- Python 3.x
- Requests library
- Internet connection

### Run Basic Version

```bash
python final.py
```

### Run Advanced Version

```bash
python gpt.py
```

### Input

Enter an IPv4 or IPv6 address when prompted.

Leave the input empty to detect your own public IP.

### Output Information

- IP Address
- IP Version
- City
- Region
- Country
- Postal Code
- Timezone
- ISP / Network
- Latitude and Longitude
- Google Maps Link

### Troubleshooting

- Check your internet connection.
- Install dependencies using `pip install -r requirements.txt`.
- Verify that the entered IP address is valid.
- Check IPAPI service availability.
