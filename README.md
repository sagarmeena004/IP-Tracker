
# Python IP Address Tracker

A Python-based IP Address Tracking tool that retrieves IP-related information using the IPAPI service.

## Features

- IP Address Lookup
- Automatic Public IP Detection
- IPv4 and IPv6 Validation
- City and Region Information
- Country and Country Code
- Postal Code Detection
- ISP / Network Information
- Timezone Detection
- Latitude and Longitude
- Google Maps Location Link
- Error Handling
- API Request Timeout Protection

## Project Files

| File | Description |
|---|---|
| final.py | Basic IP Tracker |
| gpt.py | Advanced IP Tracker |
| requirements.txt | Required Python Libraries |
| .gitignore | Git Ignore Configuration |

## Technologies Used

- Python
- Requests Library
- IPAPI
- IP Address Module

## Installation

1. Clone the repository:

   git clone https://github.com/YOUR_USERNAME/IP-Tracker.git

2. Open the project folder:

   cd IP-Tracker

3. Install dependencies:

   pip install -r requirements.txt

## Usage

### Basic Version

python final.py

### Advanced Version

python gpt.py

Enter an IP address when prompted.

Leave the input empty to look up your own public IP address.

## API Used

https://ipapi.co/
